⚠️
【開発方針】補正係数の自動適用は行いません (PHASE15)

少数データによる誤補正や異常値の偏りを防止するため、本フェーズでは分析・候補生成・信頼度評価の蓄積のみを行います。 技術者による妥当性確認と承認フローを経た後、次フェーズ（PHASE16）でCalculation Engineへ組み込まれます。
